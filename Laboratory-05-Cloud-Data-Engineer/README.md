# Laboratory 05: The Cloud Data Engineer

## Mission Overview
In this mission I acted as a Cloud Data Engineer at CloudNova Technologies. I researched the three main types of cloud storage, then deployed an S3-compatible object storage server (MinIO) using Docker on KillerCoda, created a bucket named `client-photos`, and uploaded a test file through the web console.

## Objectives
- Differentiate between Block, File and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service through a web interface using port forwarding
- Create a storage bucket and upload objects to the cloud
- Document cloud storage operations using Markdown
- Continue expanding my GitHub Cloud Computing Portfolio

## Tools Used
- KillerCoda Playground (Ubuntu)
- Docker
- MinIO (S3-compatible object storage)
- GitHub
- Web browser

## Skills Learned
- Explaining the differences between block, file and object storage
- Deploying a storage server with `docker run` using port mappings and environment variables
- Accessing a web console through KillerCoda port forwarding
- Creating buckets and uploading objects
- Documenting cloud operations in Markdown
